# Think Like an Engineer — Command Center

A dark engineering-style operations dashboard for the Think Like an Engineer project.

## Features
- Animated central business network
- Simulated connected services
- Live-looking revenue, users, course sales and agent telemetry
- Animated event stream
- Revenue velocity visualization
- Working-agent panel
- Rotating fictional customer activity
- Clickable integration telemetry cards
- Responsive layout

> **Demo notice:** all revenue, customer, visitor, payment, webhook and integration telemetry displayed by this front-end is simulated demo data. No real third-party APIs or financial accounts are connected.

## Files
- `index.html` — dashboard structure
- `style.css` — visual system and animations
- `script.js` — front-end simulation and interactions
